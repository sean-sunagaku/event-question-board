# Event Question Board

イベントで質問を集め、みんなで投票し、司会者が回答済み・強調表示を操作するOSSです。
日本語の参加者画面・管理画面・共通APIを、それぞれ独立したサービスとして公開します。
Sites版とセルフホスト版は同じソースを使います。

**現在の状態: 初期仕様・Codex Cloudへの実装指示を準備中。アプリの実装・公開はまだです。**
実装状況と公開の証拠は [docs/progress.md](docs/progress.md) で確認してください。

## リポジトリ構成

```text
apps/
  participant/       # 参加者画面と必要なサーバー処理。独立デプロイ
  admin/             # 管理画面と必要なサーバー処理。独立デプロイ
  api/               # 質問・投票・回答済み・強調表示、永続DB。独立デプロイ
packages/
  contracts/         # APIの型、入力検証、共通の契約
  ui/                # 共有UI・スタイル
  core/              # 共有のドメイン処理。必要なものだけ
docs/                # 仕様・開発手順・公開結果
scripts/             # セットアップ・確認用のコマンド
```

これは1つのモノレポです。3つのアプリを別々のSitesとして公開し、共有部分をworkspace packageで参照します。
公開用に生成する配布物を除き、共通ソースのコピーを別々に保守しません。

## 開発

Node.js 22以上とnpmを使います。初期段階の確認は以下です。

```sh
npm ci
npm run check:bootstrap
```

アプリ実装時に、DB初期化・3サービスの一括起動・型チェック・テスト・ビルド・E2Eのコマンドを追加します。
未実装の起動コマンドを実行済み・完成済みとは表示しません。
セルフホスト開発にSitesアカウントやホスティング用の秘密情報を要求しないことが完了条件です。
